# Decision log

One line of reasoning per decision. Newest last. The fixed decisions in [prd.md](prd.md#fixed-decisions) are not repeated here.

| Date | Area | Decision | Why |
|---|---|---|---|
| 2026-10-15 | Repo | Layout: `apps/web` plus `packages/{domain,ui,grader,mock-model,templates,evals,simulator,loadtest}` | One package per stream, as the PRD asks; the mock model gets its own package so its stream can work in parallel with the pipeline |
| 2026-10-15 | Repo | The orchestrator committed the bare workspace skeleton (`pnpm-workspace.yaml`, root `package.json`, `.gitignore`) to `main` directly | The repo was empty, so there was no `main` to open a PR against; every later change goes through a PR |
| 2026-10-15 | Repo | Infra and CI owns all root config; other streams touch only their own package | Root files are where parallel streams would collide |
| 2026-10-15 | Grader | `packages/grader` defines `ModelClient`, an Effect service whose one operation takes a model id and messages and returns the completion with usage and cost, or a typed error (rate limit, timeout, provider error, bad response). `packages/mock-model` provides a Layer for it | Lets the pipeline and mock streams start at once against one agreed interface; the grader stream may refine the shape in its first PR and tells the mock stream |
| 2026-10-15 | Secrets | Local secrets file is `.env.local` at the repo root | Read by Vite and the Vercel CLI by default |
| 2026-10-15 | Infra | Kincaid supplies `NEON_API_KEY` and `ELECTRIC_API_TOKEN`, not per-environment Electric source credentials | With API access, agents create Neon branches, enable logical replication and create an Electric source per preview from the CLI, so Kincaid does setup once |
| 2026-10-15 | Infra | `MODEL_CLIENT=mock` is the default everywhere; real calls need `MODEL_CLIENT=openrouter` | One explicit opt-in flag protects the $20 budget; the grader stream reads it |
| 2026-10-15 | Grader | `ModelClient.complete(request)` takes model, messages (text and image parts), a call tag (purpose, subject id, load-test run id) and optional max tokens, temperature and JSON schema; returns id, answering model, text and usage with provider-reported cost; errors are `RateLimited`, `Timeout`, `ProviderError`, `BadResponse`, with `isRetryable` | The tag carries what the call log needs without a second API; `purpose` maps onto the PRD's budget lines so the usage report can compare spend per line |
| 2026-10-15 | Grader | Effect 3 (`^3.22`), not Effect 4 | The PRD fixes `@effect/sql-drizzle`, whose latest release still requires Effect 3; every package should share one Effect major |
| 2026-10-15 | UI | Goblins' live site is goblins.com (goblins.ai does not serve it); the design language is measured from goblins.com and the public start of app.goblinsapp.com onboarding | Those are the only public surfaces; computed styles give exact colors, sizes and radii instead of guesses from screenshots |
| 2026-10-15 | UI | Nunito (OFL, via Fontsource) stands in for Goblins' ABC Ginto Rounded | Ginto Rounded is a paid license; Nunito has the same rounded terminals and heavy weights, and self-hosting avoids a Google Fonts request. Approved by Kincaid |
| 2026-10-15 | UI | Grade colors: lime for full credit, sun yellow for partial, soft peach for low, lilac for "needs you", dashed grey for "couldn't grade"; no red on student work | The PRD requires the product never make students anxious; lilac sits outside the score ramp so teachers read it as a different kind of cell |
| 2026-10-15 | UI | Tokens ship as plain CSS custom properties (`--gb-*`) plus a Tailwind v4 `@theme` file; the package exports source (no build step) | Works for plain CSS and Tailwind consumers alike; Vite compiles workspace TS and CSS directly, so a build adds nothing |
| 2026-10-15 | UI | Light theme only | Classrooms project in bright rooms and school laptops default to light; dark mode would double the visual QA for little use |
| 2026-10-15 | UI | Screenshots of goblins.com stay out of the repo; DESIGN.md links the live pages instead | They contain Goblins' logo and photos of real teachers |
| 2026-10-15 | UI | Components are thin wrappers over Base UI with plain CSS (`gb-*` classes, variants as `data-*` attributes), not Tailwind classes | Consumers need no Tailwind content scanning of the package, and Base UI's own state attributes (`data-open`, `data-highlighted`) style the same way |
| 2026-10-15 | UI | Student avatars are 48 generated creatures with names, every one a unique color and head-top pair | Distinct at a glance in a class of 30, no licensed art, and a name gives each a screen-reader label |
| 2026-10-15 | UI | A student sees "Teacher will check" for both "needs the teacher" and "couldn't grade" | The PRD shows students no error states; the difference matters only to the teacher |
| 2026-10-15 | UI | Body text is near-black green (`--gb-ink-900`); headings stay brand green. Approved by Kincaid | Goblins' marketing pages set all copy in brand green, but dense dashboard tables read better with darker body text |
| 2026-10-15 | Tooling | Biome for lint and format, one config at the root | One fast tool instead of ESLint plus Prettier and their plugin configs; its recommended rules plus `noExplicitAny` cover what AGENTS.md asks for |
| 2026-10-15 | Tooling | TypeScript 7 (the native compiler), one strict base config with `exactOptionalPropertyTypes` and `noUncheckedIndexedAccess` | Typecheck is several times faster on every CI run; Effect recommends both flags. A package whose tooling needs the TypeScript 6 JS API may pin `typescript@6` locally |
| 2026-10-15 | Tooling | No Turborepo or Nx; root scripts call `pnpm -r` | Nine small packages build in seconds; a task runner adds config without a measurable win |
| 2026-10-15 | Templates | Templates come from Illustrative Mathematics practice problems on im.kendallhunt.com: IM 6–8 Math (© Open Up Resources and Illustrative Mathematics) and IM 9–12 Geometry (© Illustrative Mathematics), both CC BY 4.0 | CC BY allows commercial use and adaptation with attribution; IM is widely used, so teachers recognize the problems, and its practice sets have diagrams, multi-part problems and dependent parts |
| 2026-10-15 | Templates | Rejected EngageNY/Eureka Math (CC BY-NC-SA), the newer IM 360 editions (CC BY-NC) and CK-12 (CC BY-NC) | Goblins is a business, so non-commercial licenses are out; share-alike would also bind our derived worksheets |
| 2026-10-15 | Templates | We use the Illustrative Mathematics name only in attribution text, never the logo | IM's name and logo are excluded from its CC license |
| 2026-10-15 | Templates | Worksheets are assembled from IM's HTML practice pages (verbatim text and diagrams, re-laid out with answer space and an attribution footer), and each `template.json` states the changes | IM publishes practice problems as web pages, not printable PDFs; CC BY requires indicating changes |
| 2026-10-15 | Templates | Answer keys are solved and written by us, not copied from IM's teacher materials | IM's keys sit behind a teacher login; solving each problem also forced a check of every diagram |
| 2026-10-15 | Templates | Four templates (Grade 7 angles, Grade 8 equations, Grade 8 linear relationships, HS Geometry trigonometry), not five | They cover every case the brief asks for (diagrams, dependent parts, a problem across two pages, plain skills practice) in both middle and high school; a fifth adds key-writing time without a new case |
| 2026-10-15 | Templates | A "solve each" problem with several unlettered equations is one problem whose answer lists every solution | That is how the page prints it, so extraction ground truth matches what a model sees |
| 2026-10-15 | Templates | The problem that runs across two pages comes from the layout: the painting problem in `linear-relationships` starts at the bottom of page 1 and part b, which uses part a, is on page 2 | Real handouts break long problems across pages; the build checks the break against the answer key |
| 2026-10-15 | E2E | E2E runs on GitHub's `deployment_status` event against the Vercel preview URL, not a server started in CI | Tests the real deploy (Neon branch, Electric, Queues) as the PRD asks; Vercel reports each preview to GitHub as a deployment |
| 2026-10-15 | E2E | Each person in a test gets their own browser context, students on a phone profile | Separate contexts don't share cookies or storage, like separate devices, so resume-by-name and per-device state are tested for real |
| 2026-10-15 | Infra | Vercel Queues push mode with `maxConcurrency` on the `queue/v2beta` trigger; no Postgres jobs-table fallback | A probe deploy showed the cap is enforced exactly (cap 2 and cap 10 never exceeded) even though the docs don't list the field. With a backlog, capped delivery adds several seconds per slot (60 five-second jobs at cap 10 took 129 s), so set the cap at the provider's limit, not below it |
| 2026-10-15 | Infra | Whiteboard Blob store `goblins-whiteboards` is private | Student work should not sit at guessable public URLs; the app reads blobs server-side or through short-lived signed URLs |
| 2026-10-15 | Infra | `OPENROUTER_API_KEY` is set only on Vercel production; previews and CI use the mock | A preview or CI run can't spend the $20 budget by accident |
