| 2026-10-15 | Grader | The call log stores a `status_code`: the HTTP status, or the code in OpenRouter's 200 error body. OpenRouter responses that are 200 but cut off at max tokens, empty, or missing usage are `BadResponse`; a 200 with an `error` body is `ProviderError` with that code | OpenRouter reports upstream failures inside 200 bodies; a grade without known cost would break cost-per-grade numbers |
| 2026-10-15 | Grader | OpenRouter responses that are 200 but cut off at max tokens, empty, or missing usage are `BadResponse`; a 200 with an `error` body is `ProviderError` with that code | OpenRouter reports upstream failures inside 200 bodies; a grade without known cost would break cost-per-grade numbers |
| 2026-10-15 | Grader | Grade jobs carry only `{ gradeId, attempt }`; every write is conditional on the row being open for that attempt; the queue idempotency key is `grade:<id>:<attempt>` | Makes duplicate, racing and stale (pre-teacher-retry) deliveries harmless under at-least-once delivery |
| 2026-10-15 | Grader | Transient model errors are retried by the queue with 2 s → 60 s capped, jittered backoff for up to 15 minutes, then `couldnt_grade`; unusable answers retry inline, 3 tries; 4xx other than 408/429 fail at once | 15 minutes is 3× the PRD's 5-minute outage, and the 60 s cap brings grades back within a minute of recovery; waiting grades hold no concurrency slot |
| 2026-10-15 | Grader | Push-mode concurrency cap is `maxConcurrency` on the `queue/v2beta` trigger, starting at 100 | The JS SDK has no option for it, but Vercel's build schema accepts it (1 to 8192); 100 in flight at about 4 s per call is about 25 grades/s, roughly 4× a 1,000-student testing day's average. Unverified until the first deploy; the PRD's Postgres jobs-table fallback stays available |
| 2026-10-15 | Grader | A cron runs every minute and re-sends grades left in `submitted` or `grading` for 3 minutes | The submit path commits before it sends, so a crash between the two would otherwise lose the grade; the idempotency key makes re-sending safe |
| 2026-10-15 | Grader | Messages are kept for 7 days, the maximum | A broken consumer deploy then delays grades until it is fixed instead of dropping them after the 24-hour default |
| 2026-10-15 | Grader | Load-test grades are routed to the mock by the grade row's `loadTestRunId`, not by a flag in the message | The database is the source of truth; a forged or replayed message cannot send a load-test grade to the paid model |
